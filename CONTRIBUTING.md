# Contributing to UltimaRobe

Please open an issue before undertaking a large change. Small fixes can go directly to a pull request. Be respectful, use synthetic fixtures, and keep personal photos and credentials out of issues and commits.

Include relevant checks from [development instructions](docs/DEVELOPMENT.md). Changes to sprite geometry should show a generic before/after example and check alpha coverage, alignment, and garment cuts. Preserve upstream attribution.

Especially welcome: easier installation, accessibility, better custom-avatar alignment, faithful garment silhouettes, and regression tests. This is a volunteer preview; response times are not guaranteed.
